📊 一、BPMN 画图要点

1. 核心元素速记（画图必用）

元素形状用途考试提示
Start Event 开始事件细线圆 ⭕流程起点每个流程只有一个开始
End Event 结束事件粗线圆 ⭕流程终点可以有多个结束
Task / Activity 任务圆角矩形 ▭执行的工作（动词）找句子里的动词
Exclusive Gateway 排他网关菱形 + ✕二选一（如果/否则）XOR，只走一条路
Parallel Gateway 并行网关菱形 + ＋同时进行AND，所有路都走
Inclusive Gateway 包容网关菱形 + ○多选一OR，可走多条
Sequence Flow 顺序流实线箭头 →先后顺序连接所有元素
Message Flow 消息流虚线箭头 ⇢跨泳道通信不同 Pool 之间
Pool / Lane 泳道水平分隔条区分角色/部门按参与者分泳道

2. 画图五步法

① 找开始：找"每天/当…时/开始" → 画开始事件
② 找活动：找句子里的动词（备份、检查、发送、更新…）→ 画任务
③ 找决策：找"如果/否则/若" → 画排他网关；找"同时/并行" → 画并行网关
④ 找结束：找"完成/取消/结束" → 画结束事件
⑤ 连起来：用顺序流按先后连接，注意网关的每条分支都要标注条件
💡 得分技巧：网关分支上必须写条件（如"有新记录/无新记录"），这是画图题的主要扣分点！

🔀 5. XOR vs AND 网关 · 可视化对比（必考区别）

左侧二选一 · 右侧全并行 · 点击按钮看 token 流动，直观理解“无并行 vs 并行同步”

XOR · 排他网关

二选一、无并行

Exclusive Gateway · 菱形 ×

token 只走一条 另一条不触发
XOR (Exclusive) Gateway: Only one outgoing path is selected based on conditions, no parallel execution. XOR（排他）网关：根据条件只选一条路径，无并行执行。
AND · 并行网关

全都要、并行同步

Parallel Gateway · 菱形 +

分支A 分支B · 同时分叉 汇合等待同步
AND (Parallel) Gateway: All outgoing paths execute in parallel and synchronize after all paths complete. AND（并行）网关：所有路径并行执行，全部完成后同步。
对比项XOR 排他网关AND 并行网关
触发条件满足条件的那一条才走（if / else）无条件，全部触发
并行性No parallel 无并行，二选一Parallel 有并行，同时执行
同步点汇合时直接通过，无需等待汇合网关等待所有分支到达才继续（同步）
典型关键词如果 / 否则 / 若 …则同时 / 并行 / 并且 / 与此同时
画图标志菱形 ×菱形 ＋
💡 补充：Inclusive (OR) 网关 是 XOR + AND 的结合 — 条件满足的多条路径都可以走，可走 1 条或多条，最后在汇合处同步。考试较少单考，但要知道它与 XOR/AND 的区别：XOR=二选一、AND=全都要、OR=满足的都要。

🏛️ 二、ArchiMate 画图要点

1. 三层速记（从上到下）

层描述常见元素例子
Business Layer
业务层		业务本身：谁参与、做什么流程参与者、角色、流程、服务、对象患者、医生、挂号流程、医疗服务
Application Layer
应用层		软件系统：用什么软件支撑业务应用组件、应用服务、数据对象挂号系统、电子病历、药房系统
Technology Layer
技术层		硬件基础设施：软件跑在哪节点、设备、网络、系统软件服务器、数据库、网络

2. 核心关系（画图必用）

  • Serving（服务）：上层服务由下层支撑 —— 业务服务 ← 应用服务 ← 技术服务
  • Realization（实现）：下层实现上层 —— 应用组件实现业务服务
  • Composition（组成）：整体由部分组成 —— 流程由多个活动组成
💡 核心思想：三层从上到下是 业务 → 应用 → 技术，每一层支撑上一层（Business supported by Application, Application supported by Technology）。画图时用箭头从下层指向上层。
