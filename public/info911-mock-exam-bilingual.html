1.2 Normalization & Standardization

2 Marks

Given a dataset $X = \{3, 6, 8, 10, 18\}$. Compute:
(1) The Min-Max normalization value of $8$ to the range $[0, 1]$.
(2) The Z-score standardization value of $18$ (using sample standard deviation $s$).

给定数据集 $X = \{3, 6, 8, 10, 18\}$。计算：
(1) 数值 8 在范围 $[0, 1]$ 内的最小-最大归一化值。
(2) 数值 18 的 Z-Score 标准化值（使用样本标准差 $s$）。

✔ 手算步骤与计算器按键
(1) Min-Max 归一化计算：
公式：$x' = \frac{x - \min(X)}{\max(X) - \min(X)}$。此处 $\min = 3, \max = 18$。
对于 $x = 8$：
x' = (8 - 3) / (18 - 3) = 5 / 15 = 1/3 ≈ 0.333
(2) Z-Score 标准化计算：
步骤 1：算均值 $\mu = \frac{3+6+8+10+18}{5} = \frac{45}{5} = 9$。
步骤 2：计算偏差平方和： $$\sum (x_i - \mu)^2 = (3-9)^2 + (6-9)^2 + (8-9)^2 + (10-9)^2 + (18-9)^2 = 128$$ 根据题目要求选择分母：
• 方法 A：使用样本标准差 $s$（分母用 $n-1 = 4$）： $$s = \sqrt{\frac{128}{4}} = \sqrt{32} \approx 5.657$$ $$Z_{18} = \frac{18 - 9}{5.657} \approx 1.59$$ • 方法 B：使用总体标准差 $\sigma$（分母用 $N = 5$）： $$\sigma = \sqrt{\frac{128}{5}} = \sqrt{25.6} \approx 5.060$$ $$Z_{18} = \frac{18 - 9}{5.060} \approx 1.78$$ *(注：在之前的 Handoff 记录中算出的 1.78 即为使用总体标准差的结果。考场上请根据题意决定使用方法 A 或方法 B。)*

2.2 SOM Dimensions

2 Marks

Suppose we use a Self-Organizing Map (SOM) to map $1,000$ input samples (each has $20$ features) onto a $10 \times 10$ grid of neurons.
(1) How many codebook vectors will be learned in total?
(2) What is the dimensionality of each codebook vector?

假设我们使用自组织映射 (SOM) 将 1000 个输入样本（每个样本具有 20 个特征）映射到大小为 $10 \times 10$ 的神经元网格上。
(1) 总共将学习出多少个参考向量 (Codebook Vectors)？
(2) 每个参考向量的维度是多少？

✔ 考场英语答题模板（复制背诵）
(1) The number of codebook vectors is equal to the number of neurons, which is 10 x 10 = 100 codebook vectors. (2) The dimensionality of each codebook vector is equal to the input features dimensionality, which is 20-dimensional.
💡 大白话秒懂 SOM 结构：
自组织映射 (SOM) 的本质，就是把高维空间的点投射到一个2D的棋盘（神经元网格）上进行无监督聚类。
输入样本 (1000个)    --> 每个样本是 20 维向量 [x1, x2, ..., x20]
       │
       ▼ (计算距离)
2D神经元网格 (10x10) --> 棋盘共有 100 个格子 (神经元)
                        每个格子都持有一个 20 维的 "代表向量" (Codebook Vector)
                        用来和输入样本算距离，谁近就判给谁！
一句话死记硬背公式：
1. Codebook Vector 的个数 = 神经元总个数 = 网格行数 × 网格列数（此题 $10 \times 10 = 100$）。与输入样本数（$1000$）完全无关！
2. Codebook Vector 的维度 = 输入样本的特征数（此题 $20$ 维）。因为它们需要计算欧氏距离，维度必须一模一样！
🧠 SOM 考前必看核心考点清单（防简答题）：
1. 它是干嘛的？
它是一个无监督的聚类与降维 (Unsupervised Clustering and Dimension Reduction) 算法。主要用于将看不见的高维数据分布在 2D 棋盘上做可视化展示。
2. 它的核心特征是什么？
保留拓扑结构 (Preserve Topology)：在高维空间中离得近的样本，映射到 SOM 网格（棋盘）上也必然靠得很近。
3. 它的训练过程 (3个核心词，默写模板)：
• Competition (竞争): 计算样本到所有神经元的距离，选出最近的作为胜者 BMU (Best Matching Unit)。
• Cooperation (协作): 确定以 BMU 为中心的邻域范围，周围神经元一起被激活。
• Adaptation (更新): 调整 BMU 及其邻域内的神经元权重，使它们都向输入点靠近。
* 随着训练进行，学习率和邻域大小都会逐渐衰减 (Decay/Shrink)。

3.2 Neural Network Weights Parameter Count

2 Marks

For a fully connected Multilayer Perceptron (MLP) with:
• Input layer dimension: $D_1$
• Output layer dimension: $D_2$
• Two hidden layers with neuron counts: $L_1$ and $L_2$ respectively.
Compute the total number of connection weights parameters in this network (excluding bias parameters). Does this count depend on the number of training samples $N$ or the training iterations $T$?

对于一个全连接多层感知机 (MLP)：
• 输入层维度为 $D_1$，输出层维度为 $D_2$。
• 包含两个隐藏层，神经元个数分别为 $L_1$ 和 $L_2$。
计算该网络中连接权重参数的总数（不包含偏置 bias ）。该参数量是否取决于训练样本数 $N$ 或训练迭代次数 $T$？

✔ 考场英语答题模板（复制背诵）
1. The total number of connection weight parameters is: (D_1 * L_1) + (L_1 * L_2) + (L_2 * D_2). 2. No. The number of parameters depends purely on the network architecture, and is independent of the number of training samples N or training iterations T.
💡 大白话秒懂神经网络参数计算：
神经网络的“全连接”意味着：前一层的每一个节点，都要跟后一层的每一个节点连一条线。 每一条连线就代表一个权重（Weight）。
这个网络可以看作有 4 层，它们是一节一节连起来的火车车厢： 
输入层 (D1个点)  =======> 隐藏层1 (L1个点) =======> 隐藏层2 (L2个点) =======> 输出层 (D2个点)
               [D1 * L1 条线]             [L1 * L2 条线]             [L2 * D2 条线]
把三段连线数加在一起，就是总连接数：$(D_1 \times L_1) + (L_1 \times L_2) + (L_2 \times D_2)$。

🧱 物理直观比喻（为什么不取决于 N 和 T）：
* 网络参数（权重和偏置）就像是大楼结构里的螺丝钉。当设计图纸画完（$D_1, L_1, L_2, D_2$ 确定）之后，螺丝钉的总数就已经被完全焊死了。
* 训练样本数 $N$ 就像是“要进出这栋大楼的人流量”。不管来 1 个人还是 1 万个人，大楼里的螺丝钉数量都不会增加或减少。
* 迭代次数 $T$ 就像是“清洁工打扫这栋大楼的次数”。打扫 1 遍和打扫 10 遍，同样不会改变钢筋里的螺丝钉个数。
* 所以，参数量只与网络架构有关，与 $N$ 和 $T$ 毫无关系。

3.4 Proof: Linear Activation in Multi-layer Network

2 Marks

Prove mathematically that a multi-layer neural network with multiple hidden layers will collapse into a single linear model if all activation functions are linear.

在数学上证明：如果所有激活函数都是线性的，那么具有多个隐藏层的多层神经网络将退化为一个单一的线性模型。

✔ 考场推导与答题模板（复制背诵）
Let the linear activation function be f(z) = z. For a network with L hidden layers: - Layer 1 output: a_1 = W_1 * x + b_1 - Layer 2 output: a_2 = W_2 * a_1 + b_2 = W_2 * (W_1 * x + b_1) + b_2 = (W_2 * W_1) * x + (W_2 * b_1 + b_2) By induction, the output of the final layer L+1 can be written as: y = (W_L+1 * ... * W_2 * W_1) * x + Constant_term Let W_total = W_L+1 * ... * W_2 * W_1 and b_total = Constant_term, we get: y = W_total * x + b_total which is a single linear model. Since the composition of linear functions is always linear, multiple hidden layers with linear activation are mathematically equivalent to a single linear layer.
💡 大白话秒懂“线性叠加依然线性”：
很多同学看不懂这段证明，是因为被数学归纳法（By induction）标答唬住了。其实这只是初中代数的代入消元法！

我们假设一个只有 2 个隐藏层的极简网络： 
第 1 层输出：a1 = W1 * x + b1  (因为激活函数是线性 f(z)=z，直接去掉激活函数 f)
第 2 层输出：a2 = W2 * a1 + b2
我们把第 1 层的 $a_1$ 结果强行代入第 2 层： $$a_2 = W_2 \times (W_1 \times x + b_1) + b_2$$ 把括号展开： $$a_2 = (W_2 \times W_1) \times x + (W_2 \times b_1 + b_2)$$ 由于两个矩阵相乘依然是一个新矩阵，我们可以令新权重 $W_{total} = W_2 \times W_1$；
由于一堆常数和矩阵相乘相加依然是一个新偏置，我们可以令新偏置 $b_{total} = W_2 \times b_1 + b_2$。
代入后式子就缩水成了： $$a_2 = W_{total} \times x + b_{total}$$ 这不就是一个最普通不过的单层线性模型（即没有隐藏层的线性回归）吗？！这说明即使加了隐藏层，网络仍然退化成了一个单一的线性模型。

🧱 物理直观比喻：
* 线性激活：就像是“把苹果切块”，再“将苹果块榨成汁”。不管你重复套用多少层这套操作（切 10 次，榨 10 次），你做出来的依然只能是“苹果汁”（线性性质不变，无法解决复杂的分类任务）。
* 非线性激活（如 ReLU/Sigmoid）：就像是“把苹果拿去发酵酿成了酒”。这是一个质的变化（非线性），能拟合极其复杂、弯弯曲曲的非线性分类边界。

4.1 Apriori Main Steps

1 Mark

Describe the main steps of the Apriori algorithm for mining frequent itemsets. Explain how it generates and prunes candidate itemsets.

简述 Apriori 算法挖掘频繁项集的主要步骤。解释它是如何生成和剪枝候选项集的。

✔ 考场英语答题模板（复制背诵）
1. Generate frequent 1-itemsets (L1) by scanning the dataset. 2. Self-join: Join L_k with itself to generate candidate (k+1)-itemsets (C_k+1). 3. Pruning (Apriori Property): A candidate itemset is pruned if any of its subsets is not frequent. 4. Support Counting: Scan the database to count the support of remaining candidates, and keep those meeting min_sup to form frequent (k+1)-itemsets (L_k+1). 5. Repeat until no new frequent itemsets are found.
💡 大白话秒懂 Apriori 的爆款组合筛选：
Apriori 算法的目标是：从一堆超市购物小票里，找出大家最喜欢一起买的“商品爆款组合”。

为了防止盲目组合导致计算量爆炸，它引入了两个名单：
• $C_k$ (Candidate 候补名单)：待考察的候选组合（比如可能会火的 2 件套、3 件套组合）。
• $L_k$ (Frequent 频繁名单)：经过数小票验证，真正达标的爆款组合。

带入超市购物场景看这 5 步：
1. 第 1 步：扫单品（生成 L1）：
把所有小票扫一遍，数数每个单品被买了几次。把销量达标的单品留下来（比如 $\{$啤酒$\}$, $\{$尿不湿$\}$, $\{$面包$\}$ 销量合格，形成单品爆款榜 $L_1$）。
2. 第 2 步：组队（Self-join，生成 C2 候补）：
既然只有这三个单品是爆款，那两两组合才可能也是爆款。我们把 $L_1$ 里的商品两两组队，生成候选 2 件套榜单 $C_2$（包括 $\{啤酒, 尿不湿\}$，$\{啤酒, 面包\}$，$\{尿不湿, 面包\}$）。此时还没数销量，只是候补。
3. 第 3 步：剪枝（Pruning，核心精髓）：
* 铁律（Apriori性质）：“如果一个组合是频繁的，它的子集也必须是频繁的；反之，如果一个单品根本不是爆款，包含它的任何大组合也绝对不可能成为爆款”。
* *例子*：你想生成候选 3 件套。如果 $\{$辣条$\}$ 根本不在单品爆款榜 $L_1$ 里，那么任何包含它的 3 件套组合（如 $\{啤酒, 尿不湿, 辣条\}$）直接被划掉扔垃圾桶（剪枝），连去数小票的工夫都省了！
4. 第 4 步：数小票（Support Counting，生成 L2 爆款）：
把剩下的、没有被剪枝的候选 2 件套，去所有购物小票里数它们的销量。销量达标的，晋升为 2 件套爆款榜 $L_2$。
5. 第 5 步：无限循环：
拿着 2 件套爆款榜 $L_2$ 两两组合，生成候选 3 件套 $C_3 \to$ 剪枝 $\to$ 数小票得到 $L_3 \dots$ 一直循环，直到组不出新名单为止。
📝 极简手算推演案例（带你完整走一遍循环）：
假设我们有 4 个交易事务 (购物小票)：
• T1: {A, B, C}      • T2: {A, B, D}
• T3: {A, C}         • T4: {B, C, D}
并设定最低出现次数门槛：$min\_sup = 2$ 次 (支持度为 50%)。

第一轮循环 (寻找 1-项集)：
1. 数单品销量，形成候选名单 $C_1$:
    {A}: 3次,  {B}: 3次,  {C}: 3次,  {D}: 2次
2. 因为销量全部 $\ge 2$ 次，全部入选第一轮爆款榜 $L_1$:
    $L_1 = \{ \{A\}, \{B\}, \{C\}, \{D\} \}$

第二轮循环 (寻找 2-项集)：
1. 连接组队 (Self-join): 把 $L_1$ 中的 4 个单品两两排列组合，形成候选名单 $C_2$:
    $C_2 = \{ \{A,B\}, \{A,C\}, \{A,D\}, \{B,C\}, \{B,D\}, \{C,D\} \}$
2. 剪枝 (Pruning): 无需剪枝（因为 A, B, C, D 本身全都在爆款榜上）。
3. 翻小票数数 (Support Counting)并过滤，留下销量 $\ge 2$ 的组合成为爆款榜 $L_2$:
    • {A, B}: 2次 (出现在T1, T2) $\to$ 保留
    • {A, C}: 2次 (出现在T1, T3) $\to$ 保留
    • {A, D}: 1次 (出现在T2)       $\to$ 小于2，淘汰！
    • {B, C}: 2次 (出现在T1, T4) $\to$ 保留
    • {B, D}: 2次 (出现在T2, T4) $\to$ 保留
    • {C, D}: 1次 (出现在T4)       $\to$ 小于2，淘汰！
4. 最终得到 2-项集爆款榜 $L_2$:
    $L_2 = \{ \{A,B\}, \{A,C\}, \{B,C\}, \{B,D\} \}$

第三轮循环 (寻找 3-项集，高频考点)：
1. 连接组队 (Self-join): 只有前缀相同的 2-项集才能合体成 3-项集：
    • $\{A, B\}$ 和 $\{A, C\}$ 前缀都是 A，合体 $\to \{A, B, C\}$
    • $\{B, C\}$ 和 $\{B, D\}$ 前缀都是 B，合体 $\to \{B, C, D\}$
    得出候选榜单 $C_3 = \{ \{A,B,C\}, \{B,C,D\} \}$。
2. 剪枝 (Pruning，高光避坑步): 拆开查小弟在不在 $L_2$ 上：
    • 对于候选 $\{A, B, C\}$: 子集有 $\{A,B\}$, $\{A,C\}$, $\{B,C\}$。经查，它们全部都在爆款榜 $L_2$ 里！说明安全，保留。
    • 对于候选 $\{B, C, D\}$: 子集有 $\{B,C\}$, $\{B,D\}$, $\{C,D\}$。经查，因为上面的 $\{C, D\}$ 已经由于销量不足被淘汰了（不在 $L_2$ 里），所以直接淘汰 $\{B, C, D\}$（剪枝），根本不用去数数了！
    因此，候选 $C_3$ 里只剩下一个独苗：$\{A, B, C\}$。
3. 翻小票数数 (Support Counting):
    • {A, B, C}: 1次 (只出现在T1) $\to$ 小于 2，淘汰！
4. 最终得到 3-项集爆款榜 $L_3 = \emptyset$ (空)。

循环结束！ 我们成功挖掘出所有的频繁组合为：$L_1$ 和 $L_2$。

4.2 Mathematical Proof: Anti-monotone of Confidence

2 Marks

Let $L = \{A,B,C,D\}$ denote a frequent itemset. Use it to mathematically show that "confidence of rules generated from the same itemset has an anti-monotone property".

令 $L = \{A,B,C,D\}$ 代表一个频繁项集。用它在数学上证明：“由同一个频繁项集生成的规则，其置信度具有反单调性”（即规则前件越长，置信度越高；前件越短，置信度越低）。

✔ 考场推导与答题模板（背诵公式）
1. Let rule r1 be: X2 → L \ X2, and rule r2 be: X1 → L \ X1, where X1 ⊂ X2 ⊂ L. 2. The confidence of r1 is: Conf(r1) = Support(L) / Support(X2). 3. The confidence of r2 is: Conf(r2) = Support(L) / Support(X1). 4. Since X1 ⊂ X2, by the anti-monotone property of support, we have: Support(X2) ≤ Support(X1). 5. Since the numerator Support(L) is identical and the denominator Support(X2) ≤ Support(X1), we conclude: Support(L) / Support(X2) ≥ Support(L) / Support(X1) which means Conf(r1) ≥ Conf(r2). Thus, confidence is anti-monotone with respect to the length of the rule antecedent (LHS).
💡 大白话秒懂“前件越长，置信度越高”：
这个定理是在说：对于同一个频繁项集，你的前件（条件）包含的商品越多，规则的置信度就越高。

推导核心：
* 置信度公式：$Conf(X \to Y) = \frac{Support(X \cup Y)}{Support(X)}$。
* 因为我们是从同一个频繁项集 $L$ 拆出来的规则，所以分子 $Support(X \cup Y) = Support(L)$ 是一个固定不变的常数。
* 既然分子固定，那么置信度的大小完全由分母 $Support(X)$（即前件的支持度）决定。
* 前件 $X_2$ 包含的商品比 $X_1$ 多（$X_1 \subset X_2$），根据支持度的反单调性（买大套餐的人肯定比买单品的人少），分母 $Support(X_2) \le Support(X_1)$。
* 分母越小，分数反而越大。所以 $Conf(r_1) \ge Conf(r_2)$。

🛒 生活直白比喻：
假设频繁项集是 $\{啤酒, 尿不湿, 面包\}$： * 规则 1（前件长，分母小，置信度高）：买 $\{啤酒, 尿不湿\}$ 的人里，有多少人会买 $\{面包\}$？（条件极其精准苛刻，筛选出来的分母很小，所以在这个特定群体里买面包的概率很高）。 * 规则 2（前件短，分母大，置信度低）：只买 $\{啤酒\}$ 的人里，有多少人会买 $\{尿不湿, 面包\}$？（条件非常宽泛，分母极大，在这个大群体里同时买另外两样东西的概率自然就变低了）。

2 Marks

Construct a small transaction dataset containing $10$ transactions for items $\{A, B, D, F, H\}$ such that the rule $\{A, D\} \Rightarrow \{F, H\}$ has a support of $0.3$ and a confidence of $0.6$. Show your calculations.

✔ 考场推导与答题模板（可复制）
Calculations: 1. Total transactions N = 10. 2. Support({A, D} => {F, H}) = 0.3 → Number of transactions containing all items {A, D, F, H} must be: 10 * 0.3 = 3. 3. Confidence = Support({A, D, F, H}) / Support({A, D}) = 0.6 → Support({A, D}) = 0.3 / 0.6 = 0.5. 4. Therefore, the number of transactions containing {A, D} must be: 10 * 0.5 = 5. 5. ✔ 考场英语答题模板（复制背诵）
Linear regression predicts continuous values that can fall outside the [0, 1] range, making it impossible to interpret the output directly as probabilities for binary or categorical classes.
💡 大白话物理图像：
线性回归的本质是画一根无限延伸的笔直铁轨 ($y = wx+b$)。
  • 概率的底线： 概率只能在 0 到 1 之间 (0% ~ 100%)。
  • 铁轨的尴尬： 如果自变量 $x$ 极其大或极其小，线性回归预测出的值 $y$ 就会是 3.5 或者 -0.8。这在数学上完全没法解释成“有 350% 的概率”或者“有 -80% 的概率”属于某个类别。
⚠️ Louis 避坑提问：既然深度学习都用 ReLU，为啥这里还要提 Sigmoid？
这是因为激活函数在“隐藏层”与“输出层”的分工完全不同：
  1. 中间隐藏层（负责提炼特征）：用 ReLU。 它的公式是 $y = \max(0, x)$。因为网络很深，如果中间用 Sigmoid，数值太大或太小时导数（斜率）接近 0，会产生梯度消失导致模型学不动；而 ReLU 计算极快，且正半区斜率恒为 1，完美解决了这个问题。
  2. 最后一层输出层（负责做二分类判决）：用 Sigmoid。 哪怕你中间用 ReLU 提炼得再好，最后一层你依然需要给出一个 $0 \sim 1$ 之间的概率。ReLU 在正半区是无限延伸的（无法直接代表概率），所以必须在最后一层套一个 Sigmoid，强行把任何得分压缩到 $[0, 1]$ 之间。
⚡️ 归纳口诀：
“隐藏层用 ReLU 当发动机（避免梯度消失，跑得快）；输出层用 Sigmoid 当裁判员（限流在 0 到 1 之间输出概率）。”

5.2 Slack Variables & Tuning Parameter C

2 Marks

Explain the relationship between the slack variables $\epsilon_i$ and the tuning parameter $C$ in the soft margin classifier. How does $C$ affect model overfitting?

解释软间隔分类器中松弛变量 $\epsilon_i$ 与调节参数 $C$ 之间的关系。$C$ 的大小如何影响模型过拟合？

✔ 考场英语答题模板（复制背诵）
1. Slack variables epsilon_i measure the distance by which the i-th observation violates the margin. 2. The parameter C limits the sum of slack variables (sum of epsilon_i <= C). 3. If C is very large, we allow large margin violations, which leads to a wider margin, high bias but low variance (prevents overfitting). 4. If C is very small, we enforce strict margins with minimal violations, which leads to a narrow margin, low bias but high variance (prone to overfitting).
⚠️ SVM 考场最阴险地雷：C 到底控什么？
在做选择题或判断题时，一定要先看清题目中的 $C$ 放在了公式的什么位置！

形式一：限制项约束形式（对应上面的英文标答）
限制公式为：$\sum \epsilon_i \le C$
* 大白话：此时 $C$ 是“犯错的上限总预算”。
* $C$ 极小（预算很紧）：不允许任何人越界，必须严防死守。这等价于硬间隔，容易过拟合 (Overfitting)，方差高。
* $C$ 极大（预算很宽）：随便犯错，越界也无所谓。这会导致间隔变得非常宽，容易欠拟合 (Underfitting)，偏差高。

形式二：目标函数惩罚项形式（机器学习教材中最常见的写法，如 ISLR）
目标公式为：最小化 $\frac{1}{2}||w||^2 + C \sum \epsilon_i$
* 大白话：此时 $C$ 是“对于犯错的惩罚力度”。
* $C$ 极大（惩罚极重，铁面无私）：谁犯错就狠狠罚谁。为了免受惩罚，模型必须严丝合缝地把所有点分类正确。这会导致间隔变窄，容易过拟合 (Overfitting)，方差高。
* $C$ 极小（惩罚极轻，得过且过）：你犯错我也不怎么管。模型会为了让间隔更宽而无视一些错误。这会导致间隔变宽，容易欠拟合 (Underfitting)，偏差高。

⚡️ 秒杀口诀：
“作为预算，C越大越宽容（防过拟合）；作为惩罚，C越大越严苛（易过拟合）。”

Explain how Random Forest works for regression tasks and discuss how it improves predictions compared to a single decision tree.

✔ 考场英语答题模板（复制背诵）

Random Forest improves predictions by significantly reducing model variance compared to a single tree, preventing overfitting, and smoothing out noise and outliers.
💡 大白话物理图像：
随机森林的本质是“三个臭皮匠顶个诸葛亮”的集体智慧（Ensemble）。
  • 随机选样本 —— 行随机（Bootstrap Sampling）： 假设我们要建 50 棵树。每建一棵新树，都在原始数据里“有放回地随机抽样”，导致每棵树看到的复习资料都有微妙区别。
  • 随机选特征 —— 列随机（Random subset feature selection）： 在决策树的每一个分叉节点上，不把所有特征都拿来选，而是随机挑一部分特征（比如只在“年龄”和“GPA”里挑），在这部分随机特征里选最好的去分叉。

⚡️ 为什么它比单棵决策树（Single Tree）更好？
  1. 降低方差（Reducing Variance）： 单棵树极易钻牛角尖（过拟合，高方差）。随机森林通过 50 棵树的联合表决，即使有个别树钻了牛角尖，平均一下就会被“拉回正轨”，大大防止了过拟合 (Overfitting)。
  2. 平滑噪音（Smoothing out noise/outliers）： 脏数据或异常值最多只影响分到它们的极少数树，当所有树一起平均时，这些噪声的影响会被大流“平滑抵消”掉。
⚡️ 归纳口诀：
“样本有放回（Bootstrap），特征随缘挑（Subset）；回归求平均（Average），防钻牛角尖（降方差，防过拟合）。”

6.2 2022 真题手算决策树多分类熵

4 Marks

A classification task uses a decision tree. Suppose in the root node, you have 10 observations of class 1, 10 of class 2, and 10 of class 3. Following the first split, you have:
• Left Node: 4 class 1, 3 class 2, 4 class 3
• Right Node: 6 class 1, 7 class 2, 6 class 3
Compute the entropy gain or loss.

决策树分类任务中，根节点有 10 个类别1，10 个类别2，10 个类别3的样本。进行第一次分裂后得到：
• 左子节点：4个类1，3个类2，4个类3。
• 右子节点：6个类1，7个类2，6个类3。
计算这次分裂的熵增益 (Entropy Gain)。

✔ 详细步骤与计算器公式
Step 1: Compute Parent node entropy: H(parent) = -3 * (1/3)*log2(1/3) = log2(3) ≈ 1.585 Step 2: Compute Left node entropy (4, 3, 4), N_left = 11: H(left) = log2(11) - (4*log2(4) + 3*log2(3) + 4*log2(4)) / 11 Calculator keys: [ln(3)/ln(2)] = 1.585. Numerator = 4*2 + 3*1.585 + 4*2 = 20.755 Divide by 11: 20.755 / 11 = 1.887 Subtract from log2(11) [ln(11)/ln(2) = 3.459]: H(left) = 3.459 - 1.887 = 1.572 Step 3: Compute Right node entropy (6, 7, 6), N_right = 19: H(right) = log2(19) - (6*log2(6) + 7*log2(7) + 6*log2(6)) / 19 Calculator keys: [ln(6)/ln(2)] = 2.585, [ln(7)/ln(2)] = 2.807 Numerator = 6*2.585 + 7*2.807 + 6*2.585 = 50.669 Divide by 19: 50.669 / 19 = 2.667 Subtract from log2(19) [ln(19)/ln(2) = 4.248]: H(right) = 4.248 - 2.667 = 1.581 Step 4: Compute Entropy Gain: H(children) = (11/30)*H(left) + (19/30)*H(right) = (11/30)*1.572 + (19/30)*1.581 = 1.578 Entropy Gain = H(parent) - H(children) = 1.585 - 1.578 = 0.007.

7.2 Precision, Recall & SVM Classifier Selection

3 Marks

Given the confusion matrices of three SVM classifiers:
• Classifier 1 (Linear SVM): TN = 275, FP = 35, FN = 32, TP = 230.
• Classifier 2 (RBF kernel, γ = 1): TN = 278, FP = 32, FN = 9, TP = 253.
• Classifier 3 (RBF kernel, γ = 500): TN = 298, FP = 12, FN = 82, TP = 180.
(1) Compute the precision and recall for all three classifiers.
(2) Choose the best classifier and justify your decision.

给出三个 SVM 分类器的混淆矩阵：
• 分类器 1 (线性 SVM)：TN = 275, FP = 35, FN = 32, TP = 230。
• 分类器 2 (RBF 核, γ = 1)：TN = 278, FP = 32, FN = 9, TP = 253。
• 分类器 3 (RBF 核, γ = 500)：TN = 298, FP = 12, FN = 82, TP = 180。
(1) 计算三个分类器的精确率 (Precision) 和召回率 (Recall)。
(2) 选择最好的一个分类器并给出合理解释。

✔ 考场英语答题模板与计算步骤
1. Precision and Recall Calculations: • Classifier 1: Precision = 230 / (230 + 35) = 230 / 265 ≈ 86.79% Recall = 230 / (230 + 32) = 230 / 262 ≈ 87.79% • Classifier 2: Precision = 253 / (253 + 32) = 253 / 285 ≈ 88.77% Recall = 253 / (253 + 9) = 253 / 262 ≈ 96.56% • Classifier 3: Precision = 180 / (180 + 12) = 180 / 192 = 93.75% Recall = 180 / (180 + 82) = 180 / 262 ≈ 68.70% 2. Selection and Justification: Classifier 2 (RBF kernel, γ = 1) is the best. Reason: It achieves the highest recall (96.56%) while maintaining a high precision (88.77%), outperforming the other two classifiers on overall balance. Classifier 3 has high precision but unacceptably low recall (misses too many positive cases).
💡 考场公式秒杀与对比技巧：
1. 分子永远是 $TP$（预测和真实都是阳性，即真阳）。
* Precision (精确率)：量的是“你预测为正的数据里，有多少是猜对的”。
分母是**你预测为正的总数** $= TP + FP$（预测正且对 + 预测正却错）。
* Recall (召回率)：量的是“真实世界里所有的正数据，你到底抓漏了多少”。
分母是**实际上为正的总数** $= TP + FN$（你抓到的正 + 你漏掉的正）。

2. 为什么分类器 3 虽然 Precision 极高，但不是最好的？
* 分类器 3 虽然精确率高达 93.75%（极少抓错），但它的召回率只有 68.70%（漏掉了超过 30% 的真实正样本，即 $FN=82$ 太多了！）。这属于严重欠拟合/漏报。
* 分类器 2 实现了两者的**完美平衡 (Trade-off)**，它的 Recall 高达 96.56%（几乎把正样本一网打尽），且 Precision 依然保持在 88.77% 的高水平。
* 在 SVM 的 RBF 核中，$\gamma$ 越大，模型越复杂（越容易过拟合）。分类器 3 的 $\gamma = 500$ 显然太大，导致了极高的过拟合（训练集完美，测试集大范围漏报）。
