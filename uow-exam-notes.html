🔵 CSCI968 高级网络安全

⭐ 第1优先级：5道高频题答案（必背！至少30分！）

Q1: Explain Diffie-Hellman (DH) protocol and Man-in-the-Middle (MITM) attack.

DH (Diffie-Hellman) is a key agreement protocol that allows two parties to establish a shared secret over an insecure channel without transmitting the secret itself. In MITM (Man-in-the-Middle) attack, attacker intercepts public keys from both parties, replaces them with his own public key, establishes separate shared secrets with both sides, can read and modify all traffic between them. DH（迪菲-赫尔曼）是一种密钥协商协议，允许双方在不安全的信道上协商一个共享密钥，而不需要传输密钥本身。在MITM（中间人）攻击中，攻击者拦截双方的公钥，替换成自己的公钥，与双方分别建立共享密钥，可以读取和篡改双方之间的所有流量。

Q2: What is DMZ (Demilitarized Zone) network? What systems are typically deployed in DMZ?

DMZ (Demilitarized Zone) is a network segment separated from internal network by firewalls, hosts public-facing services to reduce internal attack surface. Typical systems: Web servers, mail servers, DNS (Domain Name System) servers, public API (Application Programming Interface) gateways. DMZ（非军事区）是一个通过防火墙与内部网络隔离的网络段，托管面向公众的服务，以减少内部攻击面。典型系统：Web服务器、邮件服务器、DNS（域名系统）服务器、公共API（应用程序编程接口）网关。

Q3: What are the main improvements of TLS 1.3 (Transport Layer Security) over TLS 1.2?

1. 1-RTT (Round-Trip Time) handshake (faster connection setup) 2. Removes insecure cipher suites (RSA key exchange, 3DES (Triple Data Encryption Standard)) 3. Enforces forward secrecy by default 4. Simplified handshake process reduces attack surface 1. 1-RTT（往返时间）握手（更快的连接建立） 2. 移除不安全的密码套件（RSA密钥交换、3DES（三重数据加密标准）） 3. 默认强制前向保密性 4. 简化的握手过程减少攻击面

Q4: Difference between IPSec (Internet Protocol Security) Transport mode and Tunnel mode?

- Transport mode: Only encrypts the payload of IP (Internet Protocol) packet, used for end-to-end communication (client to server) - Tunnel mode: Encrypts the entire IP packet, used for site-to-site VPN (Virtual Private Network) - 传输模式：仅加密IP（互联网协议）数据包的有效载荷，用于端到端通信（客户端到服务器） - 隧道模式：加密整个IP数据包，用于站点间VPN（虚拟专用网络）

Q5: What are the differences between AH (Authentication Header) and ESP (Encapsulating Security Payload) in IPSec?

- AH (Authentication Header): Only provides integrity and authentication, no encryption - ESP (Encapsulating Security Payload): Provides both encryption, integrity and authentication, is the most widely used IPSec protocol - AH（认证头）：仅提供完整性和认证，不加密 - ESP（封装安全载荷）：同时提供加密、完整性和认证，是最常用的IPSec协议

  • TCP/IP 5层 Link → Internet → Transport → Application (TCP (Transmission Control Protocol), UDP (User Datagram Protocol)) 链路层→网际层→传输层→应用层（TCP（传输控制协议）、UDP（用户数据报协议））
  • 三大安全属性 Confidentiality (Encryption), Integrity (MAC (Message Authentication Code)), Authenticity (Digital Signature) 机密性（加密）、完整性（消息认证码）、真实性（数字签名）
  • PKI (Public Key Infrastructure) 核心 CA (Certificate Authority), X.509 standard, CRL (Certificate Revocation List), OCSP (Online Certificate Status Protocol), Monopoly/Web of Trust trust models CA（证书颁发机构）、X.509标准、CRL（证书撤销列表）、OCSP（在线证书状态协议）、垄断模型/信任网络信任模型
  • 前向保密性 Compromise of long-term keys doesn't compromise past session keys, implemented via DHE (Ephemeral DH)/ECDHE (Elliptic Curve Ephemeral DH) 长期密钥泄露不影响过去的会话密钥，用DHE（临时DH）/ECDHE（椭圆曲线临时DH）实现
  • 密钥传输vs协商 Transport (RSA: one generates and sends), Agreement (DH: both contribute) 密钥传输（RSA：一方生成发给另一方）、密钥协商（DH：双方共同生成）
  • Kerberos V5改进 Cross-realm authentication, AES (Advanced Encryption Standard) encryption, forwardable/proxiable tickets, anti-replay 跨域认证、AES（高级加密标准）加密、可转发票据、抗重放攻击
  • SSH (Secure Shell) 三层 Transport Layer (Encryption), User Authentication Layer, Connection Layer (Port Forwarding) 传输层（加密）、用户认证层、连接层（端口转发）
  • 邮件安全 PGP (Pretty Good Privacy, Web of Trust, personal use) / S/MIME (Secure/Multipurpose Internet Mail Extensions, CA, enterprise use) PGP（相当好的隐私，信任网络，个人用）、S/MIME（安全多用途互联网邮件扩展，CA，企业用）
  • TLS/DTLS/QUIC TLS (Transport Layer Security, TCP), DTLS (Datagram TLS, UDP), QUIC (Quick UDP Internet Connections, HTTP/3 (Hypertext Transfer Protocol 3)) TLS（传输层安全，TCP用）、DTLS（数据报TLS，UDP用）、QUIC（快速UDP互联网连接，HTTP/3用）
  • WEP (Wired Equivalent Privacy) 弱点 24-bit IV (Initialization Vector) repeats, no key management, easy to crack 24位IV（初始化向量）重复、无密钥管理、易破解
  • WPA/WPA2/WPA3 WPA (Wi-Fi Protected Access, TKIP), WPA2 (AES-CCMP), WPA3 (SAE (Simultaneous Authentication of Equals) handshake) WPA（Wi-Fi保护访问，TKIP）、WPA2（AES-CCMP）、WPA3（SAE（同等同时认证）握手）
  • IDS (Intrusion Detection System) NIDS (Network-based IDS), HIDS (Host-based IDS), Signature/Anomaly detection NIDS（网络级IDS）、HIDS（主机级IDS），特征匹配/异常检测

🟢 CSCI927 面向服务软件工程

⭐ 第1优先级：5道高频题答案（必背！至少30分！）

Q1: List and explain 4 core BPMN (Business Process Model and Notation) elements.

1. Event: Circle shape, represents start/end/intermediate points in a process 2. Activity: Rounded rectangle, represents a task or work to be executed 3. Gateway: Diamond shape, represents decision point (XOR (Exclusive OR)/AND (Logical AND)/OR (Inclusive OR)) 4. Sequence Flow: Arrow, shows the order of execution between elements 1. 事件：圆形，表示流程的开始/结束/中间点 2. 活动：圆角矩形，表示要执行的任务或工作 3. 网关：菱形，表示决策点（XOR（排他OR）/AND（逻辑AND）/OR（包含OR）） 4. 顺序流：箭头，显示元素之间的执行顺序

Q2: What are 4 core principles of microservices architecture?

1. Single responsibility: Each service owns one single business capability 2. Independent deployment: Services can be deployed without affecting other services 3. Decentralized data: Each service manages its own database, no shared database 4. Loose coupling: Services communicate via standard APIs (Application Programming Interfaces), no tight dependencies 1. 单一职责：每个服务拥有一个单一的业务能力 2. 独立部署：可以部署服务而不影响其他服务 3. 去中心化数据：每个服务管理自己的数据库，无共享数据库 4. 松耦合：服务通过标准API（应用程序编程接口）通信，无紧密依赖

Q3: What are the three main types of process mining?

1. Process Discovery: Generate a process model from event logs, no prior model needed 2. Conformance Checking: Compare event logs with existing process model to detect deviations 3. Performance Analysis: Analyze bottlenecks, waiting times and throughput of the process 1. 流程发现：从事件日志生成流程模型，不需要先前的模型 2. 一致性检查：对比事件日志与现有流程模型以检测偏差 3. 性能分析：分析流程的瓶颈、等待时间和吞吐量

Q4: Explain the three layers of ArchiMate model.

1. Business Layer: Describes business processes, actors and business services (e.g., customer, order process) 2. Application Layer: Describes software applications and application services (e.g., CRM (Customer Relationship Management) system, payment service) 3. Technology Layer: Describes hardware and infrastructure (e.g., servers, databases, networks) 1. 业务层：描述业务流程、参与者和业务服务（例如客户、订单流程） 2. 应用层：描述软件应用和应用服务（例如CRM（客户关系管理）系统、支付服务） 3. 技术层：描述硬件和基础设施（例如服务器、数据库、网络）

Q5: What is the difference between XOR (Exclusive) gateway and AND (Parallel) gateway in BPMN?

- XOR (Exclusive) Gateway: Only one outgoing path is selected based on conditions, no parallel execution - AND (Parallel) Gateway: All outgoing paths are executed in parallel, synchronize after all paths complete - XOR（排他）网关：根据条件仅选择一条输出路径，无并行执行 - AND（并行）网关：所有输出路径并行执行，在所有路径完成后同步
